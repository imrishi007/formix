# Formix minor-project report

This folder is ready to upload to Overleaf as a ZIP project.

## Build on Overleaf

1. Create a new project and choose **Upload Project**.
2. Upload `Formix_Minor_Project_Report_Overleaf.zip`.
3. Keep `pdfLaTeX` as the compiler and `main.tex` as the main document.
4. Select **Recompile from scratch** so the contents, figures, tables, listings,
   citations, and page numbers are generated in the correct order.

## Before final submission

- Replace the plagiarism-certificate placeholder with the signed university output.
- Confirm the guide's preferred honorific and signature blocks.
- If required by the department, change the cover month in `main.tex`.
- Run the final PDF through the university plagiarism system.
- Inspect every page once in Overleaf, especially wide screenshots and long tables.

The report follows the chapter order supplied in `table of content.docx`, uses the
format of `front page(4).docx`, and reconciles the technical content from `FORMIX.docx`
with the current repository implementation and verified test results.
